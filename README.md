## 만든 방식

- `index.html` 한 파일. 빌드 없이 GitHub Pages로 배포한다.
- 프로젝트 데이터는 페이지 안의 JS 배열에 두고 화면에 그린다.
- 히어로 문장은 형광펜(읽어 줌)과 검은 마스킹(가림) 애니메이션으로 두 주제를 표현했다.
- 비식별 프로젝트는 실제 문서 대신 가짜 개인정보로 만든 "마스킹 전/후" 예시 화면과, 실제 실행 결과 숫자로 웹 콘솔 동작을 다시 그린 화면으로 보여 준다.
- `assets/`에 프로젝트 시트 이미지(webp)와 손끝옷장 실행 영상을 둔다. 시트는 눌러서 크게 볼 수 있다.
- 키보드 포커스 표시, 예시 화면의 `aria-label` 설명을 넣었다.
